## 保留的行为

- 作者旁显示“点击查看粉丝数”；不点击不查询，也不自动展开缓存数字。
- 先搜索排序，再点右下角“查看当前前20条粉丝数”；只处理当前已加载列表，后面的仍可单查。
- 插件不设小时或每日次数额度；保留串行至少3秒、30分钟缓存、同作者去重、进度和停止。
- 网站要求登录、验证或限制访问时暂停，不能由插件取消平台自身限制。
- 不需要API Key、服务器、Cookie导出或特定AI品牌；扩展运行时没有第三方依赖。

文档覆盖Windows、macOS、Linux的环境与命令差异。原参考插件的实站证据来自Windows；本次对单份文档独立恢复后的代码做离线验证，未声称已在所有系统和所有账号完成实站测试。

运行机制与参考实现独立于XpandMax；此仓库不包含XpandMax源码、原作者的浏览器资料、安装历史或登录凭证。
